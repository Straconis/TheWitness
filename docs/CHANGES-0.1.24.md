# 0.1.24 — native Audacity projects, completion estimates and speech cleanup

Audacity exports and Soundcraft's Audacity backup now contain native `.aup3` files with embedded audio, named stereo speakers, exact rendered sample positions, intro and note markers. The original native-format writer streams decoded samples into SQLite on a worker thread, deduplicates identical blocks, represents digital silence without allocating sample blobs, and limits its JavaScript heap to 256 MiB. It preserves 16-bit PCM or losslessly maps 24-bit FLAC to float samples. The ZIP streams compression for native projects instead of storing a second uncompressed copy, and standalone Audacity ZIPs omit redundant separate processed media. Separate downloads remain available. Cancellation and errors discard partial native files, while existing files cannot be overwritten. Disk estimates account for native storage and the writer checks the recording reserve throughout. Cached legacy `.aup` exports remain downloadable.

Preparation now shows an approximate whole-export completion range alongside the current-pass ETA. A sequential work plan includes unprocessed speakers, raw copies, cleanup, silence detection/rendering, repeated loudness passes, intro matching, mixing, and packaging. Actual per-kind timing replaces broad startup assumptions as work proceeds. Completed/skipped operations leave the remaining-work ledger, and per-pass clocks accumulate inside multi-pass operations. Jobs with transcription or cloud uploads explicitly withhold an overall estimate because that time is not measured by the audio pipeline.

An off-by-default Clean up speech checkbox is available for original recordings and editor exports. The gentle preset combines 70 Hz rumble removal, up to 6 dB FFT noise reduction, a 1.5 dB presence adjustment, and a peak limiter. The filter's 25 ms delay is flushed and compensated; tests assert exact sample counts and impulse positions, including late audio. Dedicated sync cues, intro music, included raw originals and source recordings remain unchanged. Cleanup precedes original-export loudness matching. Already-cleaned editor sources are not cleaned again. Queue identity, persistence, retries, metadata and progress retain the option.

CI builds and tests the portable LGPL audio tool from pinned source checksums and packages it with the release. The installer checks the selected release binary before switching versions; older source-only releases retain their previous host-tool fallback. Whisper/model files and root-owned administration tools are unchanged. Explicit custom FFMPEG_PATH overrides are preserved and the checkbox is disabled if the selected tool lacks cleanup support.

Local validation: 264 tests passed and three optional speech tests skipped (267 total). The native tests also pass with a 512 MiB memory cap, zero swap and two CPU cores. Audacity 3.7.9 from the official checksum-verified AppImage opens a generated project with the correct stereo track/name/notes and saves it successfully. Independent checks verify exact embedded samples, silent/shared blocks, 24-bit conversion, readable compressed ZIPs, cancellation and overwrite protection. Audacity's own CompareAudio reads the embedded audio with the expected sample differences. Progress polling automatically reconnects after transient network errors while retaining the last reported step. An active VPS export must not be interrupted for this follow-up without the user's choice; 0.1.23 remains live until installation.
