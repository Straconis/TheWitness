# 0.1.8 — website icon

The Witness website now uses a bundled copy of the bot's Discord avatar as its favicon and Apple touch icon. Public HTML pages advertise the icon, and `/favicon.ico` supports browsers that request that path automatically. The avatar was retrieved from the bot's Discord profile during release preparation; later Discord-avatar changes require updating the bundled assets.

PNG/ICO assets are public, read-only resources included in normal GitHub deployments. Recording, access, queue, and log-portal behavior is unchanged.
