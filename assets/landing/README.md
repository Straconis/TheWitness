# Landing page assets

Served by fixed routes under `/assets/landing/`. The page at `/` checks for these files on each request, so adding one replaces its placeholder without a code change. Files must be committed, because deployment packages `assets/` from Git.

| File | Purpose | Status |
| --- | --- | --- |
| `banner.webp` | 1400px copy of `docs/images/discord_banner.png` for the hero | Present |
| `demo.mp4` | 30-second demo, H.264/AAC with faststart, ideally under 20 MB | Missing: "coming soon" shown |
| `sample-export.zip` | Real export of a recording whose speakers all agreed to publication | Missing: "coming soon" shown |
